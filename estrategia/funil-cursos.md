# Funil até a venda dos cursos

A ideia é construir audiência e confiança **antes** de vender.

```
Conteúdo gratuito (Reels e carrosséis)
        ↓  seguir
Iscas digitais (comenta "PROJETO" e recebe o material por DM)
        ↓  entra na lista
Lista de espera (e-mail ou grupo no WhatsApp/Telegram)
        ↓  aquece
Mini-produto ou workshop barato (validação)
        ↓  valida
Curso completo: "Projetos reais com Claude Code"
```

## Fases

### Fase 1: audiência (meses 1–3)
- Postar com consistência seguindo os [pilares](pilares.md).
- Deixar todos os projetos no GitHub, linkados na bio.
- **Meta:** descobrir quais temas geram mais salvamentos e DMs.

### Fase 2: lista (meses 3–5)
- Criar de 1 a 2 materiais gratuitos: PDF "Guia de CLAUDE.md" e template de projeto inicial.
- Usar automação de DM por palavra-chave nos comentários.
- Abrir a lista de espera do curso e perguntar à audiência o que ela quer aprender.

### Fase 3: validação (meses 5–6)
- Workshop ao vivo ou mini-curso de baixo valor (ex.: "Seu primeiro projeto com Claude Code em 2h").
- Coletar depoimentos e dúvidas. Isso vira a grade do curso completo.

### Fase 4: curso completo
Ideia inicial de módulos:
1. Setup: terminal, Git, GitHub e instalação do Claude Code
2. Fundamentos: como pedir, CLAUDE.md, plan mode e revisão de código
3. Projeto 1: site ou landing page publicada
4. Projeto 2: API com banco de dados
5. Projeto 3: SaaS com login e pagamento
6. Avançado: subagents, MCP, hooks, skills e automações
7. Colocar em produção: deploy, domínio e monitoramento

## Métricas que importam

| Fase | Métrica principal |
|---|---|
| Audiência | Seguidores/semana, salvamentos, compartilhamentos |
| Lista | Inscritos na lista, taxa de clique no link da bio |
| Validação | Vendas do workshop, respostas às pesquisas |
